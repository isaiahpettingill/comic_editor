# Keyboard shortcuts

Open **View → Keyboard shortcuts** (F1) in the app for the same quick reference.
Ctrl shortcuts also accept Cmd on macOS. Text inputs keep their normal editing
keys; tool and frame shortcuts do not run while typing. Browser/OS-reserved
shortcuts may be intercepted before they reach the app; menus remain available.

| Action | Keys |
|---|---|
| New / open / save document | Ctrl+N / Ctrl+O / Ctrl+S |
| Save as / print current frame | Ctrl+Shift+S / Ctrl+P |
| Undo / redo | Ctrl+Z / Ctrl+Shift+Z or Ctrl+Y |
| Cut / copy / paste | Ctrl+X / Ctrl+C / Ctrl+V |
| Select all in focused item list (otherwise artwork) | Ctrl+A |
| Deselect artwork | Ctrl+Shift+A |
| Move focus in item list / extend range | Up, Down / Shift+Up, Shift+Down |
| New / duplicate frame(s) | Alt+N / Alt+D |
| Delete focused frame(s), layer(s), text object(s), or selected artwork | Delete |
| Delete selected frame(s) | Alt+Delete |
| Previous / next frame | Alt+Left / Alt+Right |
| Move selected frame(s) earlier / later | Alt+Up / Alt+Down |
| Copy / paste frame | Ctrl+Shift+C / Ctrl+Shift+V |
| Frame timing and visibility | Alt+T |
| Preview cutscene | F5 |
| Edit selected text / rename artwork layer | F2 |
| Tool options / palette / selected color | F4 / F6 / F7 |
| Brush size smaller / larger | [ / ] (Shift changes by five pixels) |
| Fit / actual pixels | Ctrl+0 / Ctrl+1 |
| Zoom out / in | Ctrl+− / Ctrl++ |
| Finish / cancel polygon or curve | Enter / Escape |
| Finish inline text (retain edits) | Ctrl+Enter or Escape |
| Larger / smaller text or selected text span | Ctrl+Shift+. / Ctrl+Shift+, |

## Tools

A plain key recalls the last-used tool in that group. **Shift+key** cycles to
the next variant, including when another group is currently selected. The toolbar
tooltip shows the key; right-click or long-press still opens the variant menu.

| Key | Variants in cycle order |
|---|---|
| B | Pixel, Smooth, Pressure, Marker |
| E | Eraser |
| G | Fill |
| L | Line, Curve |
| U | Rectangle, Rounded rectangle, Ellipse, Polygon |
| I | Eyedropper |
| T | Text |
| A | Spray can, Dither |
| M | Rectangular selection, Freehand selection, Elliptical selection |
| R | Pixel scramble, Blur |
| Z | Zoom |

Ctrl+Alt combinations are left alone for AltGr layouts. Keyboard tool switching
is also ignored while a menu or combo box owns focus. Escape cancels an active
pane drag without rearranging the workspace.
